# 一覧の表示

## 表示モード

| コマンド | モード |
|---|---|
| Current.Mode.Details | 詳細 |
| Current.Mode.Thumbnail | 縮小版。サイズは 64/96/128/192/256（`Option.Thumbnail.N`、既定 96）。一覧の上で Ctrl+ホイールを回すと、96〜512 を 32 ずつ変える（上で大きく）。サイズはすべてのペインで共通 |

ほかのモード（Tile、Icon、List）と、アイコンの自動整列（Current.AutoArrange）はない。Avesta の設定ファイルにあっても、その項目は出さない。

## 詳細の列

| 列 | 内容 | 右寄せ |
|---|---|---|
| 名前 | アイコンと表示名 | |
| 状態 | クラウド同期の状態アイコン。同期ルートの配下のときだけ表示する | |
| 更新日時 | `yyyy/MM/dd HH:mm` | |
| 種類 | 種類名（`SHGFI_TYPENAME`） | |
| サイズ | `1,234 KB`（Explorer と同じ書き方。フォルダは空欄） | ✓ |
| 作成日時 | `yyyy/MM/dd HH:mm` | |
| アクセス日時 | `yyyy/MM/dd HH:mm` | |
| 属性 | Explorer と同じ文字をこの順で並べる：R（読み取り専用）H（隠し）S（システム）D（フォルダ）A（アーカイブ）C（圧縮）E（暗号化） | |

- 値が取れない項目（仮想フォルダの中など）は空欄
- 見出しをクリックすると、その列で並べ替える。もう一度で逆順
- 並べ替えは、フォルダを先に、ファイルを後にする。名前は自然順（`file2` < `file10`）で比べる
- 見出しの境界をドラッグして列幅を変える。ダブルクリックで中身に合わせる
- `Current.AdjustToItem` / `Shown.AdjustToItem`：列幅を中身に合わせる
- `Current.AdjustToWindow` / `Shown.AdjustToWindow`：名前の列をペインの幅に合わせて広げる

## 列のカスタマイズ

- 表示する列と並び順、列幅は、すべてのフォルダ・ペインで共通（config.json の `Columns` と `ColumnWidths`）
- 既定は 名前・状態・更新日時・種類・サイズ。作成日時・アクセス日時・属性は既定では表示しない
- 名前の列はいつも先頭にあり、隠せない
- 状態の列は、表示する設定でも、同期ルートの配下のときだけ出す
- 見出しを右クリック：列ごとのチェック項目と「既定に戻す」のメニュー。チェックを付けた列は右端に足す
- 見出しを左右にドラッグ：列を並べ替える（名前より左には置けない）。少し（4px）動かすまではクリック扱い
- 表示していない列で並べ替えていても、並べ替えはそのまま

## 状態列

| 状態 | 条件 | アイコン |
|---|---|---|
| 常に利用可能 | `FILE_ATTRIBUTE_PINNED` | 緑の塗りつぶしチェック |
| 利用可能 | 同期ルートの配下で、オンラインのみでも固定でもない | 緑の枠のチェック |
| オンラインのみ | `FILE_ATTRIBUTE_RECALL_ON_DATA_ACCESS` または `FILE_ATTRIBUTE_RECALL_ON_OPEN` または `OFFLINE` | 雲 |

## グループ（Current.Grouping）

並べ替えている列で分け、見出しに「名前 (件数)」を表示する。

| 列 | 区分 |
|---|---|
| 名前 | 先頭の文字（英字は大文字にする。数字は「0 - 9」、記号は「その他」、かなは「あ行」など） |
| 更新日時 | 今日 / 昨日 / 今週の前半 / 先週 / 今月の前半 / 先月 / 今年の前半 / 昨年 / かなり前 |
| 種類 | 種類名 |
| サイズ | 空 (0 KB) / 極小 (0 - 16 KB) / 小 (16 KB - 1 MB) / 中 (1 - 128 MB) / 大 (128 MB - 1 GB) / 特大 (1 - 4 GB) / 巨大 (> 4 GB) / フォルダ |
| 状態 | 状態名 |
| 作成日時 / アクセス日時 | 更新日時と同じ |
| 属性 | 属性の文字（なければ「なし」） |

## 隠しファイル（Current.ShowAllFiles）

- オフ（既定）：hidden 属性と system 属性のものを表示しない
- オン：すべて表示する。hidden のものは薄く表示する

## 選択

- クリック：その項目だけを選ぶ
- Ctrl+クリック：選択を切り替える
- Shift+クリック：範囲で選ぶ
- 空いている所からドラッグ：範囲選択
- キー操作：↑↓（縮小版では←→も）、Home、End、PageUp、PageDown、Shift と組み合わせて範囲、Ctrl と組み合わせてカーソルだけを移動、Space で選択の切り替え、先頭の文字を入力して移動
- `Current.SelectAll` / `SelectNone` / `SelectReverse` / `SelectPattern`（ワイルドカード。`;` で複数指定）

## マウス（簡単な操作だけ）

| 操作 | 動作 |
|---|---|
| 項目でないところをダブルクリック | Current.Go.Up |
| 項目でないところを中クリック | Current.Go.Up |
| 項目を中クリック | 何もしない |
| 戻るボタン / 進むボタン | Current.Go.Back / Forward |

## ステータスバーの文字（current のペインだけを表示する）

| 状況 | 文字 |
|---|---|
| 選択あり | `{選択数} / {全数} 個のオブジェクトを選択 ( {選択の合計サイズ} )` |
| 選択なし（実フォルダ） | `{全数} 個のオブジェクト ( {合計サイズ} ) / 空きディスク領域 [{ドライブ}] {空き容量}` |
| 選択なし（仮想フォルダ） | `{全数} 個のオブジェクト` |

- サイズの書き方：`0 バイト`、`1.23 KB`、`45.6 MB`（StrFormatByteSize と同じ）
- ドライブ：ドライブ文字。UNC のときはサーバー名

## フォルダごとの表示設定

- 表示モード、並べ替え（列、向き）、グループのオン/オフ、隠しファイルの表示を、フォルダのパスごとに保存する（列幅は全体で共通。「列のカスタマイズ」）
- 保存がないフォルダは、いちばん近い親フォルダの設定を使う。どこにもなければ既定（詳細、名前の昇順、グループなし）
- 設定を変えたときと終了時に保存する。7日使わなかった設定は消す（そのフォルダ、またはその下のフォルダを開けば「使った」ことになる）

## 一覧の更新

- 表示中のペインのフォルダを監視し、変化があれば 200ms まとめてから一覧を読み直す（変化が続くときも、最初の変化から 1.5 秒で読み直す）
- 非表示のペインは監視しない。非表示のタブを表示したときに、一覧を 1 回読み直す（それまでは前の一覧を出しておく）
- 読み直しの最中に次の変化が来たら、終わってから 1 回だけ読み直す（遅いフォルダで読み直しを積み上げない）
- 表示中のフォルダが無くなったとき（削除、名前の変更、ドライブの取り外し、共有フォルダの切断）：
  - 3 秒ごとに、監視しているフォルダがまだあるかを確かめる（Windows の監視は、フォルダが消えても何も知らせずに止まるため）
  - 無くなっていたら、ペインを空にして、一覧の場所に「このフォルダを開けません」と理由を出す。タブは残す
  - フォルダが戻ったら（挿し直した、つなぎ直した、同じ名前で作り直した）、自動で読み直し、監視も張り直す
  - 読み直し（F5、ファイル操作のあとなど）が失敗したときも、同じ表示にする。別のフォルダへの移動が失敗したときは、今のフォルダの表示を残して、ステータスバーに理由を出す
- 読み直しても、選択とスクロール位置はできるだけ残す
- 非表示のタブを表示し直したときは、選択は残し、スクロール位置は先頭に戻す（カーソルの行があれば、それが見える位置まで動かす）
- 読んでいる最中にフォルダが変わると、同じ項目が2回返ることがある。同じ場所の項目は1つにまとめる（2回出たままだと、行の表示が画面に残る）
- `Current.Refresh`（F5）で手動で読み直す。このとき監視も張り直す（短い切断のあとなど、監視だけが止まっていることがあるため）
- PC、ごみ箱、`\サーバー名` などの仮想フォルダは監視しない（F5 で読み直す）

## アイコンと縮小版の取得

- シェルが画像をまだ用意できていないとき（`E_PENDING`、または何も描かれていない画像。起動直後の Dropbox などの同期ルートで起きる）は、少し待って取り直す（合計で約 1.1 秒まで）。それでも取れなければ、アイコンなしにする
- 「オンラインのみ」のファイルのアイコンと縮小版を取っても、ファイルはダウンロードされない（縮小版は同期サービスが渡す。Dropbox で確認。`docs/poc.md`）
