# 画面構成

上から順に並べる。

1. **メニューバー**（menu.xml）：Alt でアクセスキー、Alt 単独でメニューにフォーカス。隠しているとき（`Menu.Show`）は、Alt 単独で表示に戻す
2. **ツールバー**（tool.xml、24px アイコン）
3. **リンクバー**（link.xml、16px のシェルアイコン）
4. **タブバー**（tabs.md）
5. **ペインの列**：shown のタブを横に並べる（数が多いときに2段に分けることもできる。tabs.md「2段に並べる」）。ペインごとに
   - アドレスバー（フォルダのアイコン、パス、ドロップダウンボタン）
   - 一覧（詳細 または 縮小版）
6. **ステータスバー**：左に current のペインの文字（listing.md）、右に status.xml のボタン。更新をダウンロードし終えたら、左端に更新のボタン（update.md）

## ウィンドウ

- タイトル：`Vesta - {current の名前} / {current のパス}`。タブがなければ `Vesta`
- 位置、大きさ、最大化を var/session.json の `window` に保存して、次の起動で戻す
  - 動かしたとき、大きさを変えたとき、閉じるときに保存する。入れるのは最大化する前の位置と大きさ（最大化中や最小化中に閉じても同じ）
  - 最小化したまま閉じても、次は最小化では開かない（その前が最大化なら最大化で開く）
  - タイトルバーがどの画面にも出ない位置（外したモニターなど）なら、画面の中へ戻す。画面より大きければ縮める
  - 保存が無い、または読めないときは、既定の大きさ（1600×900）で開く
- 閉じるときに、まだ書いていない session.json、config.json、folders.json を書いてから閉じる
- 起動するとセッションを復元する。起動引数にパスがあれば、復元したあとに、それを「外から開く」で開く（`-` で始まる引数は無視する。相対パスは、起動したときの作業フォルダから見る）
- 2つ目の起動は、引数を1つ目のウィンドウへ渡して終了する（single instance）。1つ目のウィンドウは前面に出て、渡されたパスを開く
- 復元で開けなかったタブ（つながっていない共有フォルダ、外したドライブ）は、空のままタブを残し、ペインに「このフォルダを開けません」と出す。場所が使えるようになると自動で読み直す（`docs/spec/listing.md`「一覧の更新」）。最新の情報に更新するか、隠して表示し直しても読み直す
- 復元は、応答しない場所を待たない。タブの場所の確認は 3 秒で打ち切り、開けなかったタブと同じ扱いにする。一覧の読み込みは待たずに、起動引数の処理や終了時の保存の準備へ進む
- 異常終了（パニック）したときは、`var/crash.log` に記録してメッセージを出す
- アプリを止めない問題（ドロップの受け取りを登録できなかった、仮想フォルダの一覧が途中で止まった、など）は、`var/vesta.log` に 1 行ずつ記録する。画面には出さない

## モード

ウィンドウは、いつも次のどれか 1 つのモードにある。手前にあるものが優先される（上ほど優先）。キーとコマンドを受け付けるかどうかは、モードで決まる。

| モード | いつ | キーの行き先 | コマンド |
|---|---|---|---|
| ダイアログ | 開く、場所を指定、新規作成、パターン選択、バージョン情報 | ダイアログの入力欄。Esc で閉じる（OK のないものは Enter でも閉じる） | 受け付けない |
| ポップアップ | メニューバー、ツールバー、リンクバー、タブ、列、キーに割り当てたメニューが開いている | メニュー（上下で移動、→ でサブメニュー、← と Esc で戻る、Enter とアクセスキーで実行） | メニューの項目を選ぶと、メニューを閉じてから実行する |
| OS のメニュー・ドラッグ | Explorer の右クリックメニューが出ている、Vesta から始めたドラッグの最中 | Windows が受ける | 受け付けない |
| 編集中 | アドレスバーに入力している、名前を変更している | 入力欄。キーの割り当ては動かない（例外：名前の変更中は、`Current.Rename` を割り当てたキーだけ効き、選ぶ範囲を切り替える。fileops.md） | メニューやバーからは受け付ける |
| メニューバーの強調 | Alt を単独で押したあと | ← → で移動、↓ ↑ Enter で開く、アクセスキーで開く、Esc でやめる | 受け付ける |
| 通常 | 上のどれでもない | キーの割り当て（keyboard-*.xml）。なければ一覧の組み込みのキー（矢印、Enter、Space、頭文字ジャンプ） | 受け付ける |

- Alt 単独（Alt を押して、ほかのキーもマウスも使わずに離す）は、ダイアログと OS のメニュー以外で効く。メニューバーの強調を入れ切りする。メニューが開いていれば閉じる。メニューバーを隠しているときは、表示に戻す
- Alt+文字は、メニューバーの同じアクセスキーのメニューを開く。別のポップアップが開いていれば、それを閉じて切り替える
- ポップアップの外を押すと、ポップアップを閉じる。ウィンドウがフォーカスを失っても閉じる
- ポップアップを開くと、メニューがフォーカスを持つ。ポップアップやダイアログを閉じると、フォーカスは current のペインの一覧へ戻る。名前の変更を終えたときも一覧へ戻る

### 処理中の操作

ファイルを変える操作は、1 度に 1 つだけ実行する：貼り付け、削除、完全に削除、ここにコピー、隣のペインへ移動・コピー、元に戻す、新しいフォルダー、新規作成、ドロップ、名前の変更の確定。

- 最中に次の操作をすると、1 つだけ待たせて、前が終わってから実行する
- 待ちがあるときにさらに操作をしても、受け付けない。ステータスバーに「前の操作が終わるまで待ってください」と出す
- キーを押しっぱなしにしたときの繰り返しでは、これらの操作は実行しない（Ctrl+V を押し続けても、貼り付けは 1 回）
- ほかの操作（移動、選択、タブの切り替え、表示の変更、コピーと切り取り）は、いつでも効く
- 操作が終わっていないときにウィンドウを閉じようとすると、確認を出す（fileops.md）

## バージョン情報（System.About）

- 名前、バージョン、ビルドした日時（`2026-11-11 11:40` の形、その PC の時刻）、サイト、ライセンスを出す
- ビルドした日時は、UI をビルドしたとき（`npm run tauri build` / `tauri dev` の起動時）に埋め込む。同じバージョンのまま作り直しても、どの版が動いているか分かるようにするため

## 見た目

- Windows の標準に近い見た目にする。フォントは `Yu Gothic UI`、大きさは既定で 12px（9pt 相当）
- 文字の大きさは「表示 → 文字の大きさ」で 小（11）/ 標準（12）/ 大（14）/ 特大（16）から選ぶ（config.json の `FontSize`）。メニュー、バー、タブ、一覧の行、縮小版の名前などの高さは文字に合わせて変わる。アイコンとツールバーのボタンの大きさは変えない。詳細の列の幅も、大きさを変えたときに同じ割合で伸び縮みする（状態の列はアイコンだけなのでそのまま）。列の幅の自動調整（区切りのダブルクリック、AdjustToItem）は、今の文字の大きさで測る
- 色は Windows のシステム色に近い固定の値を使う（ライトのみ）
- ペインの一覧は、Windows 10 の Explorer の詳細表示に近づける（選択は薄い青）

## 既定のバー

既定の設定ファイル（`src-tauri/resources/usr/`）の並び。

- tool.xml：戻る、進む、上のフォルダ｜閉じたフォルダを開く（MRU）、最新の情報に更新｜切り取り、コピー、貼り付け、削除、元に戻す｜新しいフォルダー｜詳細、縮小版
- status.xml：1〜9（タブの表示の切り替え）｜ロック、隠しファイル、グループ｜詳細、縮小版
- Avesta の「横に並べる」（Arrange.Horz）と「整列」（Current.AutoArrange）は無い（ペインの並べ方は横並びと、その2段だけ。整列は何もしないため）
