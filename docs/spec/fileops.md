# ファイル操作

ファイル操作はすべて IFileOperation で行う。進捗、確認、衝突のダイアログは Windows 標準のものを使う。

## コマンド

| コマンド | 動作 |
|---|---|
| Current.NewFolder | 「新しいフォルダー」を作り、その場で名前の編集を始める |
| Current.New | 名前を入力するダイアログを出す。名前に拡張子（最後の `.` の後ろに1文字以上）があれば空のファイルを、なければフォルダを作る。同じ名前があれば「(2)」などを付ける。作った項目を選ぶ |
| Current.Cut / Copy | 選択項目をクリップボードへ入れる（CF_HDROP と Preferred DropEffect） |
| Current.Paste | クリップボードのファイルを current のフォルダへ移動/コピーする。切り取った項目を最後まで移動できたら、クリップボードを空にする（もう一度貼っても、元の場所には無いため）。`PasteInFolder` がオンで、フォルダを1つだけ選んでいるときは、そのフォルダの中へ。コピーした項目を元と同じフォルダに貼ると、Current.Copy.Here と同じく「- コピー」を付けて複製する。切り取った項目を元と同じフォルダに貼っても何もしない |
| Current.Copy.Here | 選択項目を同じフォルダに複製する（「- コピー」を付ける） |
| Current.Delete | ごみ箱へ送る。ごみ箱に入らないもの（ネットワーク上、大きすぎるもの）は、完全に削除する前に Windows の確認が出る（`FOF_WANTNUKEWARNING`） |
| Current.Bury | 完全に削除する（確認あり） |
| Current.MoveToOther / CopyToOther | 次の shown ペイン（右隣。右端なら左端）のフォルダへ移動/コピーする。そのペインが同じフォルダを表示しているときは、貼り付けと同じ（移動は何もしない、コピーは複製） |
| Current.Rename | 名前をその場で編集する。`RenameExtension` がオンなら、拡張子を除いた部分を選んだ状態で始める（オフなら全体）。編集中にもう一度実行すると（既定のキーは F2）、拡張子（`.` の後ろ）を選ぶ。さらに実行すると拡張子を除いた部分を選び、以降は交互に切り替える。入力途中の文字はそのままで、そのときの文字の最後の `.` で分ける。拡張子のない名前とフォルダでは、全体を選ぶ。変えたあとも、その項目を選んだままにする |
| Current.Copy.Path / Name / Base | 選択項目のフルパス / 名前 / 拡張子を除いた名前を、改行区切りでテキストとしてコピーする。選択がなければ current のフォルダ |
| Current.Undo | 直前のファイル操作を元に戻す。削除を戻すとき、元の場所に同じ名前の項目ができていたら、上書きせずに止める |
| RecycleBin.Empty | ごみ箱を空にする（ごみ箱の「空にする」を呼ぶ。確認あり） |
| Current.Property | プロパティのダイアログ（SHObjectProperties） |

## 元に戻す

アプリの中で行った操作を、新しい順に記録する。上限は 50 件。

| 操作 | 戻し方 |
|---|---|
| 名前の変更 | 元の名前に戻す |
| 移動 | 元のフォルダへ移動し直す |
| コピー、複製、新規作成 | 作られた項目をごみ箱へ送る |
| ごみ箱へ送る | IFileOperationProgressSink::PostDeleteItem で受け取った、ごみ箱の中の項目を、元の場所と名前へ移動する |
| 完全に削除 | 戻せない（記録しない） |

- 戻せなかったときは、ステータスバーに理由を出す
- フォルダは、フォルダごと 1 つの項目として記録する（中の項目は別に記録しない）
- **同じ名前があった項目は記録しない**。コピー・移動の前に、落とす先に同じ名前の項目があったもの（上書きした、フォルダを統合した、スキップした）は、元に戻す対象から外す。Windows はこれらも「成功」として返すので、記録すると、元に戻したときに、もとからあった項目まで消してしまう。上書きされた元のファイルは戻せない（Explorer と同じ）。外したときは、ステータスバーに「同じ名前があった項目は、元に戻す対象になりません」と出す。「両方を保持」で別の名前になった項目は、ふつうに記録する
- **もとからある項目を置き換えない**。移動や削除を戻すとき、元の場所に同じ名前の項目ができていたら、その項目は戻さずに止める（確認も出さない）
- 戻せなかった項目がまだ残っているとき（上の「同じ名前」、キャンセル、エラー）は、その分を記録に残す。じゃまな項目をどけてからもう一度 Ctrl+Z を押すと、同じ操作を戻せる。対象がもう無いときは、記録から消す
- 記録はアプリを終了すると消える
- 元に戻している間も「操作の途中」に数える（下の「操作の途中で閉じるとき」）

## 結果の文字（ステータスバー）

| 状況 | 文字 |
|---|---|
| 確認やダイアログで全部を取りやめた | 操作を中止しました（続きの操作も行わない） |
| 一部だけ行われた（スキップ、途中でキャンセル） | 一部の項目は処理されませんでした |
| 同じ名前の項目を上書き・統合した | 同じ名前があった項目は、元に戻す対象になりません |

## ドラッグ＆ドロップ

- アプリから外へ：選択項目をネイティブのドラッグで出す（Explorer やほかのアプリへドロップできる）
- 外から、またはアプリの中で：ウィンドウのドロップ先（`src-tauri/src/droptarget/`）が受け取り、`drag-drop` イベント（パスと座標）でフロントへ渡す。フロントは座標の下にあるものへ入れる
  - フォルダの項目の上：そのフォルダへ
  - ペインの空いている所：そのペインのフォルダへ
  - タブの上：そのタブのフォルダへ
  - それ以外の所（メニューバー、ツールバー、リンクバー、タブバーの空いている所、ステータスバー、タブが無いときの空いた領域。ペインの中のアドレスバーはペインに含む）：落とされたもののうち、フォルダだけを「外から開く」で開く（`docs/spec/navigation.md`。落とした時点の修飾キーに従う）。ファイル、フォルダへのショートカット、パスを持たないものは無視する。左ボタンでも右ボタンでも同じで、枠の強調はしない
- 受け取るもの（上から順に調べ、最初に当てはまったものを使う）：
  1. ファイルやフォルダ（Explorer など。パスを持つ）
  2. 中身を持つ仮想ファイル（ブラウザの画像やリンク、メールの添付など。パスを持たない）
  3. URL だけ（インターネット ショートカット `.url` を作る。名前は URL のホスト名）
- 2 と 3 は「保存」として扱う：
  - 落とした時点で、中身を一時フォルダ（`%TEMP%\vesta-drop\`）に書き出し、そこから落とす先へ移動する。修飾キーは見ない
  - ファイル名は渡された名前を使う。フォルダの区切りや使えない文字は `_` に置き換え、名前だけにする（落とす先の外には書かない）。同じ名前が落とす先にあれば、通常の移動と同じ確認が出る
  - 元に戻す（Ctrl+Z）と、保存したファイルは一時フォルダへ戻る（落とす先から消える）
  - 一時フォルダは、次に起動したときに消す
  - 書き出せなかったときは、ステータスバーに理由を出す
- ドラッグ中は、落とす先（フォルダの項目、ペイン、タブ）を枠と薄い色で強調する。アプリの中から始めたドラッグでも同じ
  - 自分自身の上と、項目が今あるフォルダの上は強調しない（落としても何も起きないため）
- 右ボタンのドラッグ：
  - 一覧の項目を右ボタンで押したまま 4px 以上動かすと、ドラッグを始める（右クリックメニューは出さない）。押した項目が選択されていなければ、その項目だけを選択してから始める
  - 右ボタンのドラッグを Vesta に落とすと（Vesta の中からでも、Explorer からでも）、落とした位置に、Explorer と同じシェルのメニューを出す：「ここにコピー」「ここに移動」「ショートカットをここに作成」「キャンセル」と、ドラッグ＆ドロップ ハンドラー（FastCopy、圧縮ソフトなど）が足す項目
    - 落とす先のフォルダのシェルのドロップ先（`IShellFolder::CreateViewObject` の `IDropTarget`）に、右ボタンのドロップをやり直させる。メニューも、選んだ操作の実行も、シェルが行う
    - そのため、この操作は Vesta の「元に戻す」（Ctrl+Z）には入らない
  - シェルのドロップ先が得られないフォルダでは、Vesta のメニュー（コピー / 移動 / ショートカット / キャンセル）を出す。こちらは元に戻せる。項目が今あるフォルダへ落としたとき、「ここに移動」は選べず、「ここにコピー」は「- コピー」を付けて複製する
  - パスを持たないもの（ブラウザの画像など）は、右ボタンでもメニューを出さずに保存する
  - Vesta から Explorer などへ右ボタンで落としたときのメニューは、落とした先が出す
- コピーか移動か（左ボタンのドラッグ）：
  - Ctrl：コピー、Shift：移動、Alt または Ctrl+Shift：ショートカットの作成
  - 修飾キーなし：同じドライブなら移動、違うドライブなら `DnDCopyInterDrv`（既定オン。コマンドは `Option.DnDCopyInterDrive`）のときコピー。共有フォルダは `\\サーバー\共有名` までが同じなら同じドライブとみなす
  - 項目が今あるフォルダへ落としたとき：移動なら何もしない。コピーなら「- コピー」を付けて複製する（Current.Paste と同じ）

## 右クリックメニュー

- 項目の上：選択項目の IContextMenu（Explorer と同じメニュー）
- 空いている所：フォルダの背景の IContextMenu（新規作成、貼り付け、表示に関係しない項目）
- 「名前の変更」「削除」「切り取り」「コピー」「貼り付け」「プロパティ」は、メニューの verb を見てアプリ側のコマンド（元に戻すの記録つき）で行う

## 操作の途中で閉じるとき

- コピー・移動・削除が終わっていないときにウィンドウを閉じる（または更新して再起動する）と、確認を出す。「いいえ」なら閉じない
- 閉じると、コピーは途中で止まる（コピー先に途中までのファイルが残ることがある。移動元は、コピーが済むまで消えない）
