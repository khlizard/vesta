## ファイル操作

- [x] Current.New（既定は Ctrl+N）：`abc` でフォルダ、`abc.txt` でファイル。同じ名前があれば「(2)」。作った項目が選ばれる
- [x] ファイル `x` を作る → 削除 → フォルダ `x` を作ると、フォルダのアイコンになる
- [x] Ctrl+C / Ctrl+X / Ctrl+V、Delete（ごみ箱）、Shift+Delete（完全に削除）、F2（名前の変更）、Ctrl+Shift+N（新しいフォルダ）
- [ ] F2 で名前を変えたあとも、その項目が選ばれたまま。新しいフォルダ（Ctrl+Shift+N）は名前の編集が確実に始まる
- [ ] 同じフォルダで Ctrl+C → Ctrl+V（または Ctrl+ドラッグで同じフォルダへ）で「a - コピー.txt」ができる。Ctrl+X → Ctrl+V では何も起きない
- [x] Ctrl+Z で、名前の変更 / 移動 / コピー / ごみ箱へ送る が元に戻る
- [x] ペインからペインへのドラッグ（同じドライブは移動、別のドライブはコピー、Ctrl でコピー）
- [x] ドラッグ中、落とす先のフォルダ・ペイン・タブが枠で強調される（アプリ内のドラッグでも、Explorer からでも）。元のフォルダと自分自身の上では出ない
- [x] タブへのドロップ。非表示のタブの上で待つと表示される
- [x] Explorer へのドラッグ、Explorer からのドロップ
- [ ] フォルダをツールバー・メニューバー・リンクバー・ステータスバー・タブバーの空いている所へドロップすると、そのフォルダがタブで開く。ファイルを落としても何も起きない
- [ ] 項目を右ボタンでドラッグして別のペイン・フォルダ・タブへ落とすと、Explorer と同じメニュー（ここにコピー / ここに移動 / ショートカットをここに作成 / キャンセル、FastCopy などの拡張の項目）が出て、選んだとおりになる。右クリックメニューは出ない
- [ ] Explorer から右ボタンでドラッグして落としても、同じメニューが出る。Vesta から Explorer へ右ボタンで落とすと、Explorer のメニューが出る
- [ ] 右ボタンのメニューを、外をクリックするか Esc で閉じられる。閉じたあと何も起きない
- [ ] 動かさない右クリックでは、今までどおり右クリックメニューが出る
- [ ] ブラウザ（Chrome / Edge / Firefox）の画像をペイン・フォルダ・タブへドロップすると、画像ファイルが保存される。落とす先が枠で強調される
- [ ] ブラウザのリンクやアドレスバーの URL をドロップすると、`.url`（インターネット ショートカット）ができ、開くとそのページが出る
- [ ] 保存のあと Ctrl+Z で、保存したファイルが消える
- [ ] メールの添付（Outlook など）をドロップして保存できる

## データの安全（公開前に確かめる）

なくなって困らないファイルを入れた、試し用のフォルダで行う。

- [ ] 同じ名前のファイルがある先へコピーすると、Windows の確認が出る。「置き換える」のあと Ctrl+Z を押しても、そのファイルは消えない（ステータスバーに「同じ名前があった項目は、元に戻す対象になりません」）
- [ ] 同じ確認で「スキップ」を選び、Ctrl+Z を押しても、もとからあったファイルは消えない。「キャンセル」では「操作を中止しました」と出て、何も変わらない
- [ ] 複数のファイルをコピーして一部だけが同じ名前のとき、Ctrl+Z で消えるのは、新しくできたファイルだけ
- [ ] フォルダを、同じ名前のフォルダがある先へコピーして統合し、Ctrl+Z を押しても、もとからあった中身が残る
- [ ] 中身のあるフォルダをコピー → Ctrl+Z、移動 → Ctrl+Z で、元どおりになる
- [ ] 移動したあと、元の場所に同じ名前のファイルを作って Ctrl+Z を押すと、「同じ名前の項目があるため、戻せません」と出て、どちらのファイルも残る。そのファイルをどけてもう一度 Ctrl+Z を押すと、戻る
- [ ] 削除（ごみ箱）のあと、同じ名前のファイルを作って Ctrl+Z を押しても、上書きされない
- [ ] Ctrl+X → Ctrl+V のあと、もう一度 Ctrl+V を押すと「貼り付けるファイルがありません」
- [ ] 2 つのペインで同じフォルダを表示して MoveToOther を実行しても、何も起きない。CopyToOther は「- コピー」ができる
- [ ] USB メモリや NAS の上で Delete を押すと、完全に削除する確認が出る。削除したあとの Ctrl+Z は、この削除を対象にしない
- [ ] 別のドライブへ移動して Ctrl+Z で戻る

## 外からの変更と、つながらない場所

- [ ] Explorer やほかのアプリでファイルを作る・消す・名前を変えると、表示が追従する。選択と名前の編集は続く
- [ ] 表示中のフォルダを Explorer で消す（または名前を変える）と、数秒でペインに「このフォルダを開けません」と出る。同じ名前で作り直すと、自動で一覧が戻り、その後の変更も追従する
- [ ] USB メモリのフォルダを表示したまま抜くと「このフォルダを開けません」。挿し直すと戻る
- [ ] NAS のフォルダを表示したまま切断しても、同じ表示になる。つなぎ直すと戻る。その間、ほかのペインは操作できる
- [ ] つながらない場所のタブがある状態で起動しても、数秒でほかのタブが出る。つながらないタブには「このフォルダを開けません」と出る
- [ ] オンラインのみのファイルがあるフォルダ（Dropbox、OneDrive）を、詳細と縮小版で開いても、ダウンロードが始まらない（状態のアイコンが変わらない）
